Sistemas Organizados at Network

Declaración de Accesibilidad

Última actualización: 15 de enero de 2026

Sistemas Organizados at Network se compromete a garantizar que su sitio web denilsonarnau.com sea accesible para todas las personas, independientemente de sus capacidades físicas, sensoriales o cognitivas.

1. Situación de Cumplimiento

✓ Este sitio web es parcialmente conforme con el Real Decreto 1112/2018 sobre accesibilidad de los sitios web y aplicaciones para dispositivos móviles del sector público, adaptado al sector privado con actividad económica.

1.1. Nivel de Conformidad

Este sitio web se ha diseñado con el objetivo de cumplir con el nivel AA de las Pautas de Accesibilidad para el Contenido Web (WCAG) 2.1.

1.2. Método de Evaluación

La evaluación de accesibilidad se ha realizado mediante:

  • Autoevaluación técnica: Análisis del código y estructura del sitio web
  • Herramientas automáticas: WAVE, Lighthouse, axe DevTools
  • Revisión manual: Navegación con teclado, lectores de pantalla y pruebas de contraste
  • Fecha de evaluación: 15 de enero de 2026

2. Contenido Accesible

Elementos implementados correctamente:

  • ✓ Estructura HTML5 semántica con etiquetas apropiadas
  • ✓ Navegación mediante teclado funcional (Tab, Enter, Escape)
  • ✓ Indicadores visuales de foco (outline) en elementos interactivos
  • ✓ Formularios con etiquetas asociadas y validación accesible
  • ✓ Enlaces descriptivos que indican claramente su destino
  • ✓ Tipografías legibles y escalables (fuentes locales)
  • ✓ Diseño responsive adaptado a diferentes tamaños de pantalla
  • ✓ Modo claro/oscuro según preferencias del sistema

3. Limitaciones Conocidas

Áreas en proceso de mejora:

  • ⚠️ Algunas imágenes decorativas pueden carecer de atributo alt vacío
  • ⚠️ El carrusel de proyectos está optimizado para gestos táctiles pero podría mejorar navegación por teclado
  • ⚠️ El chatbot con IA requiere mejoras en anuncios ARIA para lectores de pantalla

Estamos trabajando activamente en resolver estas limitaciones en futuras actualizaciones.

4. Tecnologías Utilizadas

La accesibilidad de este sitio web se basa en las siguientes tecnologías:

  • HTML5: Estructura semántica del contenido
  • CSS3: Presentación visual adaptativa
  • JavaScript: Funcionalidad interactiva progresiva
  • ARIA: Atributos de accesibilidad cuando es necesario

El sitio web está diseñado para funcionar correctamente en:

  • Navegadores modernos (Chrome, Firefox, Safari, Edge) - últimas 2 versiones
  • Lectores de pantalla (NVDA, JAWS, VoiceOver)
  • Dispositivos móviles (iOS, Android)

6. Procedimiento de Aplicación

Si no está satisfecho con la respuesta recibida o considera que no se están cumpliendo los requisitos de accesibilidad establecidos, puede:

  1. Presentar una reclamación ante la empresa: A través de los canales de contacto indicados anteriormente, exponiendo detalladamente la naturaleza de la barrera de accesibilidad.
  2. Contactar con organismos de protección al consumidor: Puede dirigirse a las oficinas de consumo de su comunidad autónoma.
  3. Presentar una queja ante el Ministerio de Asuntos Económicos y Transformación Digital:

7. Información Adicional

7.1. Compromiso con la Mejora Continua

La accesibilidad es un proceso continuo. Nos comprometemos a:

  • Revisar y actualizar periódicamente esta declaración
  • Realizar auditorías de accesibilidad de forma regular
  • Incorporar mejoras basadas en feedback de usuarios
  • Mantenernos actualizados con las últimas normas WCAG

7.2. Formación y Sensibilización

El equipo de desarrollo de Sistemas Organizados at Network recibe formación continua en:

  • Principios de diseño universal
  • Estándares de accesibilidad web (WCAG 2.1)
  • Uso de tecnologías asistivas
  • Mejores prácticas de desarrollo accesible

8. Normativa de Referencia

Esta declaración de accesibilidad se ha elaborado conforme a:

  • Real Decreto 1112/2018, de 7 de septiembre, sobre accesibilidad de los sitios web y aplicaciones para dispositivos móviles del sector público
  • Web Content Accessibility Guidelines (WCAG) 2.1
  • Real Decreto Legislativo 1/2013, de 29 de noviembre, por el que se aprueba el Texto Refundido de la Ley General de derechos de las personas con discapacidad
  • Directiva (UE) 2016/2102 del Parlamento Europeo sobre accesibilidad de sitios web
